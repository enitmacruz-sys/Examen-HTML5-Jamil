LINEA DE TIEMPO DE LA HISTORIA DE HTML

▼
  • 1980 - ORIGEN: HTML El origen del lenguaje HTML se remonta al fisico Tim Berners-Lee, un trabajador del CERN quien a finales de 1980 propuso el lenguaje HTML junto con el protocolo HTTP para compartir informacion entre cientificos de todo el mundo.
  • 1989-1991 - EL PRIMER DOCUMENTO EN HTML El primer documento formal con la descripcion de HTML se publico en 1991 bajo el nombre HTML Tags (Etiquetas HTML) y todavia hoy puede ser consultado online como reliquia informatica.
  • 1993 - PROPUESTA DE ESTANDARIZACION El IETF realiza la primera propuesta oficial. Se definieron etiquetas para imagenes, tablas y formularios, pero ninguna propuesta (HTML y HTML+) consiguio convertirse en estandar oficial aun.
  • 1995 - HTML 2.0 El organismo IETF organiza un grupo de trabajo y publica, el 22 de septiembre, el estandar HTML 2.0, el cual es considerado el primer estandar oficial de HTML.
  • 1997 - HTML 3.2 Primera recomendacion publicada por el W3C. Incorpora avances como applets de Java y texto que fluye alrededor de las imagenes.
  • 1998 - HTML 4.0 Supone un gran salto: incluye hojas de estilo CSS, scripts, mejoras en accesibilidad, tablas complejas y formularios.
  • 2004 - HTML 5 Se funda el WHATWG como una alianza entre Apple, Oracle, Opera y Mozilla para comenzar con la definicion del estandar HTML 5.
  • 2010 - YOUTUBE (HTML) Sitios web de gran peso como YouTube implementan el uso del HTML 5 para sustituir el uso de la tecnologia Flash.

📄 Que es HTML5?

▼

HTML5 es la quinta version del lenguaje de marcado estandar para crear paginas web. Fue oficializado por el W3C en 2014 y es el lenguaje base de toda la web moderna.

Incluye soporte nativo para video, audio, graficos (Canvas), geolocalizacion y almacenamiento local, sin necesidad de plugins externos como Flash.

Trabaja junto a CSS3 y JavaScript, formando la triada fundamental del desarrollo web frontend.
